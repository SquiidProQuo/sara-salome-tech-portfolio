# VirtualBox Windows and Linux Home Lab

## Project Overview

I built this home lab to develop practical experience with virtualization, operating systems, command-line tools, and technical troubleshooting. The lab allows me to practice IT support and system administration tasks in an isolated environment without affecting my primary computer.

**Status:** In Progress

## Technologies Used

- Oracle VirtualBox
- Windows host computer
- Kali Linux virtual machine
- Linux command line
- Virtual storage and system resource configuration

## Work Completed

- Installed and configured Oracle VirtualBox on a Windows computer.
- Created and launched a Kali Linux virtual machine.
- Allocated virtual memory, processing resources, and storage.
- Practiced navigating the Linux file system from the command line.
- Created, copied, moved, compressed, and extracted files.
- Practiced identifying file sizes and verifying command results.
- Diagnosed startup and file-management problems through systematic troubleshooting.
